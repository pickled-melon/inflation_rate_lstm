## Развёртывание окружения

В Miniforge Prompt

```bash
conda init powershell
```

В терминале

```bash
conda env create -f environment.yml
conda activate fourth_lab

dvc remote modify local_storage url /pat/to/dvc-storage
dvc pull

nbstripout --install
```

## Экспорт зависимостей

```bash
conda env export --from-history > environment.yml
```

## Добавление файлов в dvc

```bash
dvc add data/processed/EXAMPLE.csv

git add data/processed/EXAMPLE.csv data/.gitignore

dvc push
```
